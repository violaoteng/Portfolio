## Getting Started

To run the portfolio locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/violaoteng/My-portfolio.git
   ```

2. Navigate to the project folder:

   ```bash
   cd My-portfolio
   ```

3. Open `index.html` in your browser.
